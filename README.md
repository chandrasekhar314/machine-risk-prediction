# Dynamic Machine Data Management & Local Risk Prediction

## 1. Technologies Used
- Frontend: React.js
- Backend: Spring Boot
- Database: MySQL
- Machine Learning: Python (scikit-learn, Flask API)

## 2. Setup & Run Instructions
### Backend
1. Clone repo
2. Navigate to backend folder
3. Run: `mvn spring-boot:run`
4. Backend runs at `http://localhost:8080`

### Frontend
1. Navigate to frontend folder
2. Run: `npm install`
3. Run: `npm start`
4. Frontend runs at `http://localhost:3000`

### Python ML Service
1. Navigate to `ml-service` folder
2. Run: `pip install -r requirements.txt`
3. Start service: `python app.py`
4. Service runs at `http://localhost:5000`
